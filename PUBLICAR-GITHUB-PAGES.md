# Publicação do site no GitHub Pages

1. Envie `index.html`, `style.css`, `README.md`, `projetos.md`, `frameworks.md`, `competencias.md` e `artigos.md` para a raiz do repositório `millerkbarros/portfolio-profissional`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`; clique em **Save**.
5. Aguarde a publicação e valide o endereço sugerido pelo GitHub Pages.

O site usa HTML e CSS estáticos; não precisa de build, Node.js ou dependências. O simulador PERT + Monte Carlo permanece em seu repositório próprio.
